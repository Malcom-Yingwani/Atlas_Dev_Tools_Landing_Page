# Atlas Dev Tools – Landing Page (Practice MVP)

A responsive landing page built as a **practice MVP** to explore frontend fundamentals, product thinking, and landing-page structure for a hypothetical developer productivity tool.

This project focuses on **layout, UX flow, responsiveness, and basic interaction**, rather than full backend or production-level functionality.

---

## 📌 Project Purpose

The goal of this project was to:

- Practice building a **landing-page MVP**
- Apply **HTML, CSS, and vanilla JavaScript** fundamentals
- Think through **product messaging and user flow**
- Simulate user interaction without backend complexity
- Create a deployable static site suitable for early idea validation

This is **not a full product** — it is intentionally scoped as a **practice MVP / validation page**.

---

## 🧩 What This Project Demonstrates

- Clean semantic HTML structure  
- Responsive layout (desktop, tablet, mobile)  
- Fixed navigation with smooth scrolling  
- Basic JavaScript interaction (email submission feedback)
- Simple, readable CSS without frameworks

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3** (Flexbox, media queries, CSS variables)
- **Vanilla JavaScript**
- **Font Awesome** (icons)

No frameworks or libraries were used — the focus was on core frontend skills.

---


## ⚠️ Intentional Limitations

This project **does not include**:

- Backend or database integration  
- Real email storage or submission  
- Authentication or user accounts  
- Analytics tracking  
- Production-grade accessibility auditing  

Email submission is **simulated on the client side** to demonstrate interaction and UX feedback only.
